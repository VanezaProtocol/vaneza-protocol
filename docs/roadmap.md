# Roadmap

Phases are ordered, not dated. A phase is done when its exit criteria are met, not when a calendar says so.

## Phase 0: Foundation

- Brand identity and public site at vaneza.dev
- Live chain readings (block, gas, value locked, busiest pools)
- Public ledger of confirmed facts
- Written protocol overview and architecture

**Exit:** site live, documents published.

## Phase 1: Specification

- Note format and commitment scheme fixed on paper
- Proof statements defined: ownership, value conservation, nullifier uniqueness
- Solver interface and settlement rules drafted
- Threat model written, including the limits stated in the whitepaper

**Exit:** specification reviewed in the open.

## Phase 2: Core build

- Vault contract and note accounting
- In-browser prover
- Reference solver
- Test network deployment

**Exit:** a full deposit, prove, settle, exit cycle on a test network.

## Phase 3: Review

- Independent security review of contracts and circuits
- Public bug reporting window
- Fixes and re-review

**Exit:** findings resolved and published.

## Phase 4: Release

- Mainnet deployment on Robinhood Chain
- Contract address announced through the ledger
- Documentation for users and solver operators

**Exit:** the contract record on the website reads "stated".

## Beyond

More assets, better proving speed, clearer tooling for solver operators. Prioritised by what users hit first.
