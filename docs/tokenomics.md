# Tokenomics

**Status: no token has been announced.** There is no contract address, no supply, no allocation and no sale. This page exists so the structure of the eventual decision is public before any figure is.

Any number appearing elsewhere that claims otherwise is not from this project.

## Questions this document will answer once decided

| Topic | What will be published |
|---|---|
| Existence | whether a token exists at all, and what it is for |
| Supply | total supply and whether it can change |
| Distribution | categories, shares, and who controls each |
| Vesting | schedules for team and early contributors |
| Fees | where protocol fees go and who may change them |
| Governance | which parameters, if any, token holders decide |

## Rules the project commits to

1. **No figures before facts.** Allocation numbers are published together with the contract that enforces them.
2. **Verifiable on-chain.** Vesting and distribution are checkable from the contract, not from a slide.
3. **One source of truth.** The contract address appears first on [vaneza.dev](https://vaneza.dev) and in the README, in the same form.
4. **No private rounds disguised as public ones.** If any pre-launch allocation exists, it is disclosed with the rest.

## Where updates appear

Changes are announced on the website's ledger and reflected here. Until a record there reads "stated", treat it as nonexistent.
